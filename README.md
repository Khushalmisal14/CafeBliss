# ☕ CafeBliss AI System

A smart AI-powered cafe management system built with Python Flask.

## 🚀 Features
- Customer Signup/Login with OTP verification
- AI-based food recommendation system
- AI Chatbot for customer support
- Menu management (Admin)
- Cart & Order system
- Cash & Online Payment (Razorpay)
- PDF Invoice generation
- Analytics Dashboard with Charts
- Light & Dark Mode
- Responsive Modern UI

## 🛠️ Tech Stack
- **Backend:** Python, Flask, SQLAlchemy
- **Frontend:** HTML, CSS, Bootstrap 5, JavaScript
- **Database:** SQLite
- **AI:** Rule-based ML Recommendation Engine
- **Payment:** Razorpay
- **PDF:** ReportLab

## ⚙️ Installation
```bash
git clone https://github.com/Khushalmisal14/CafeBliss.git
cd CafeBliss
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```
